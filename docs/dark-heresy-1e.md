# Dark Heresy, первая редакция

В библиотеке система имеет ID `dark-heresy-1e`. Профиль `dark-heresy-1e-ru-extended` распознаёт русский пятистраничный заполняемый лист. Он проверен на опубликованном исходнике и варианте того же листа с изменёнными примерными характеристиками.

## Получить лист

[Публикация автора перевода](https://imaginaria.ru/p/dark-heresy-character-sheet-russian-beta.html) содержит [PDF](https://imaginaria.ru/attachments/get/543) и оригинальный шрифт. Автор перевёл расширенный лист первой редакции. Лист содержит примерные характеристики; это не готовый персонаж. PDF разрешает копирование для личного использования. Загружай его в личную библиотеку:

```bash
uv run python scripts/pdf_library.py add /path/to/dark-heresy-character-sheet-5-page-printer-friendly-Rus-Writable.pdf \
  --system dark-heresy-1e --title 'Dark Heresy 1e RU · расширенный лист'
```

Профиль определяется автоматически. Через `/library` выбери Dark Heresy 1e, создай рабочую копию и заполни её. Проверь каждый примерный показатель перед игрой. Книги и памятки добавляй с той же системой и видом `rules` или `reference`; учитывай редакцию и согласованные с ведущим дополнения.

## Поддержка формы

В исходнике 5 страниц: 700 текстовых widgets, 452 флажка и 6 списков выбора типа брони. Некоторые характеристики и отметки повторяются на нескольких страницах под общим именем. Редактор синхронизирует их. Цифры характеристик находятся в отдельных полях на один символ: десятки и единицы вводятся раздельно. Ограничение длины проверяется до изменения значения; подбор шрифта сохраняет крупные цифры.

Тип брони выбирается из вариантов самого PDF. `set_choice()` принимает фактическое имя ComboBox, например `Dropdown1.0.0`. Пустая строка снимает выбор. Новый произвольный вариант отклоняется. Списки ListBox, радиокнопки и подписи остаются для просмотра. Кириллица проверена после сохранения и рендера; установленный в ОС авторский шрифт для этого пути не требуется. Внешний вид введённого текста может отличаться от оригинального Caslon Antique.

```python
from scripts.pdf_form_editor import PdfFormEditor

editor = PdfFormEditor('templates/local/my-dark-heresy.pdf')
try:
    editor.set_text('character_name', 'Имя персонажа')
    editor.set_text('player_name', 'Имя игрока')
    editor.set_text('career', 'Арбитр')
    editor.set_text('weapon_skill_tens', '3')
    editor.set_text('weapon_skill_units', '5')
    editor.set_choice('Dropdown1.0.0', 'Обычная')
    editor.autosize_text_fields('filled')
    editor.save()
finally:
    editor.close()
```

Профиль сопоставляет имя, игрока, профессию, ранг, происхождение, особенность, предсказание, ордос, три строки описания и обе цифры каждой из девяти характеристик. Остальные поля доступны по фактическим именам. Профиль не вычисляет показатели и не проверяет легальность персонажа. Конструктор или другой вариант листа с иными именами использует фактические поля либо собственный профиль.

## Проверить новый вариант

На временной копии измени русский текст, обе цифры характеристики, повторяющийся флажок и тип брони. Сохрани, открой заново и сверь значения на всех страницах. Посмотри рендер пяти страниц: текст должен помещаться, цифры должны быть читаемыми, отметки должны оставаться в нужных местах. Изменение одного повторяющегося поля должно обновить все его экземпляры. Затем выполни тесты проекта и `uv run python scripts/pdf_library.py check`.

Данные игр, заполненные листы, пользовательские шаблоны и книги хранятся в `templates/local/` и исключены из Git. Репозиторий содержит систему, профиль и инструкции импорта.
